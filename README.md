# Jhon Camilo Vásquez
**Contador Público · IA aplicada a finanzas y contabilidad**
*Public Accountant · Applied AI for finance and accounting*

Soy contador público y empecé en el trabajo de todos los días: contabilidad, impuestos, cartera, conciliaciones. Ahí aprendí que los números casi nunca fallan por la teoría; fallan en el proceso: un archivo que llega torcido, un cruce que nadie revisó, un reporte que se arma a mano cada mes.

Por eso empecé a construir las herramientas que resuelven eso. Hoy trabajo con SQL, Python y agentes de IA para automatizar lo repetitivo, validar los datos antes de confiar en ellos y dejar dashboards que la gente sí usa. Me interesa que el resultado se pueda auditar: que se sepa de dónde sale cada cifra y qué se hizo para comprobarla.

Este portafolio muestra ese trabajo: sistemas que leen estados financieros, calculan indicadores, cobran cartera y controlan proyectos. Antes de construir escribo el plan y fijo cómo voy a medir si funciona; si no pasa la prueba, no se lanza.

I'm a public accountant, and I started in the day-to-day work: accounting, taxes, receivables, reconciliations. That's where I learned that numbers rarely fail because of theory; they fail in the process: a file that arrives wrong, a match nobody checked, a report assembled by hand every month.

So I started building the tools that fix that. Today I work with SQL, Python and AI agents to automate the repetitive parts, validate data before trusting it, and ship dashboards people actually use. I care about results that can be audited: knowing where every figure comes from and how it was checked.

This portfolio shows that work: systems that read financial statements, compute indicators, collect receivables and control projects. Before building, I write the plan and decide how I'll measure whether it works; if it doesn't pass, it doesn't ship.
